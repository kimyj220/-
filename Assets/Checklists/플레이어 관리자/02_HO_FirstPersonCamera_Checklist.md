# Checklist 02. HO_FirstPersonCamera

## 검증 항목
- [x] `PlayerCameraPivot`, `Main Camera`, `HO_FirstPersonCamera` 연결 구조가 준비되어 있다.
- [x] 감도와 상하 회전 제한값이 Inspector에서 조정 가능하다.
- [x] `Mouse X`, `Mouse Y`를 쓰는 Old Input 구조로 설계되어 있다.
- [x] 회전축과 제한 목적을 설명하는 주석 작성 기준이 문서에 반영되어 있다.
- [ ] 미검증: 마우스 이동에 따라 1인칭 시점이 자연스럽게 회전한다.
- [ ] 미검증: 상하 회전 제한이 정상 동작한다.
- [ ] 미검증: 급격한 흔들림이나 멀미 유발 회전이 없다.
