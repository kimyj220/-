# Checklist 08. HO_ReactiveLighting

## 검증 항목
- [x] 조명 대상 `Light`와 발광 대상 `Renderer` 목록이 Inspector 연결 대상으로 정리되어 있다.
- [x] `HO_ReactiveLighting`가 구역 흐름, 작품 선택, 영상 재생 상태 참조를 받을 수 있게 구성되어 있다.
- [x] 전환 시간과 상태별 반응 규칙이 클래스 내부 기준으로 정리되어 있다.
- [x] 조명 전환 역할 주석이 클래스와 주요 함수에 반영되어 있다.
- [ ] 미검증: 구역 전환에 따라 조명 분위기가 바뀐다.
- [ ] 미검증: 영상 재생 또는 작품 선택 시 강조 연출이 추가된다.
- [ ] 미검증: 프레임 저하 없이 0.5~1초 내 부드럽게 전환된다.
