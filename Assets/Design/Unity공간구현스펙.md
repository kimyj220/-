# Unity 3D 공간 구현 스펙

기준 자료: `Assets/Concept/gallery_3d_floorplan_architectural.png`, `Assets/Design/콘텐츠기획.md`  
목적: 도면의 1~6번 전시 공간을 Unity 3D 씬 생성 스크립트로 옮기기 위한 좌표/치수 중심 스펙

## 0. 좌표계 및 공통 제작 기준

| 항목 | 기준 |
| --- | --- |
| Unity 좌표 | X/Z 평면이 바닥, Y가 높이 |
| 단위 | 1 Unity unit = 1 meter |
| 원점 | 공간 1 `입장 로비` 중앙 바닥점 = `(0, 0, 0)` |
| +X 방향 | 도면 기준 오른쪽, 매체 확장의 방/라운지 방향 |
| +Z 방향 | 도면 기준 위쪽, 시간의 복도/추상과 색면의 방 방향 |
| 기본 바닥 Y | `0.00` |
| 중앙 데크 Y | `0.60` |
| 외부 계단 하단 Y | `-0.45` |
| 기본 벽 높이 | `3.60` |
| 외벽 두께 | `0.35` |
| 내벽 두께 | `0.22` |
| 문/개구부 높이 | `2.40` |
| 난간 높이 | `1.05` |
| 플레이어 눈높이 | `1.65` |
| 권장 이동폭 | 최소 `1.60m`, 주요 동선 `2.20m` 이상 |

좌표 표기 규칙:

- `center`: Unity 월드 좌표 `(X, Y, Z)`
- `size`: Unity Cube 기준 스케일 `(widthX, heightY, depthZ)`
- 벽은 Cube Primitive로 생성한다.
- 작품 프레임/영상 월은 얇은 Cube 또는 Plane으로 생성한다.
- 공간은 실제 도면의 비례를 우선한 근사값이며, 구현 중 충돌/시야 확보를 위해 `±0.5m` 조정 가능하다.

Unity 기준 예시:

```csharp
player.transform.position = new Vector3(-2.8f, 0.0f, -3.9f);
camera.transform.localPosition = new Vector3(0f, 1.65f, 0f);
player.transform.rotation = Quaternion.Euler(0f, 20f, 0f);
```

## 5. 주요 벽, 문, 개구부

### 5.1 외벽/내벽 생성 원칙

| 항목 | 제작 지시 |
| --- | --- |
| 벽 Primitive | Cube |
| 벽 중심 Y | 바닥 Y + `1.80` |
| 기본 벽 size Y | `3.60`; 공간 3은 `4.00`, 공간 4는 `3.80` 가능 |
| 개구부 처리 | 벽을 여러 세그먼트로 나눠 문 폭만 비운다 |
| 유리문/창 | 얇은 Cube 또는 Plane, alpha material 적용 |
| 검은 상영실 | 벽 재질 charcoal/dark graphite, 바닥도 dark material |
