# 단계별 수행 절차

## 사용 원칙
- 모든 Task 실행은 프로토타입 범위로 제한하고, 검증에 필요한 구조와 임시 UI만 우선 구현한다.
- 입력 처리는 Old Input만 사용하고, 새로 만드는 C# 클래스 이름은 모두 `HO_` prefix를 유지한다.
- 각 Task 문서는 서브에이전트에게 개별 실행 지시하고, 해당 단계에서 필요한 범위만 구현한다.
- 아직 순서가 오지 않은 의존 클래스는 그 단계에서 구현하지 않고, 필요한 참조 슬롯만 비워 두거나 이후 단계에서 연결한다.
- Task 완료 직후 대응 Checklist를 열어 구조 확인 항목부터 체크하고, 플레이 테스트가 끝난 항목만 추가로 체크한다.

## 1. 플레이어 관리자
### 01. HO_PlayerMovement
- 대상 Task 문서 경로: `Assets/Tasks/플레이어 관리자/01_HO_PlayerMovement.md`
- 서브에이전트 실행 문구: "`Assets/Tasks/플레이어 관리자/01_HO_PlayerMovement.md`를 실행해 `HO_PlayerMovement`만 구현한다. Old Input만 사용하고 후속 카메라 클래스는 아직 구현하지 않는다."
- Unity Scene에서 할 일: `Player` 오브젝트를 만들고 `CharacterController`와 `HO_PlayerMovement`를 추가한다.
- Inspector 연결 대상: `moveSpeed`, `gravity`, `groundSnapForce` 값을 입력하고 `characterController`에는 같은 `Player`의 `CharacterController`를 연결한다.
- 완료 후 체크할 Checklist 경로: `Assets/Checklists/플레이어 관리자/01_HO_PlayerMovement_Checklist.md`

### 02. HO_FirstPersonCamera
- 대상 Task 문서 경로: `Assets/Tasks/플레이어 관리자/02_HO_FirstPersonCamera.md`
- 서브에이전트 실행 문구: "`Assets/Tasks/플레이어 관리자/02_HO_FirstPersonCamera.md`를 실행해 `HO_FirstPersonCamera`만 구현한다. 기존 `HO_PlayerMovement`를 활용하고 이후 선택, UI 계열 클래스는 아직 구현하지 않는다."
- Unity Scene에서 할 일: `Player` 하위에 `PlayerCameraPivot`과 `Main Camera`를 배치하고 `HO_FirstPersonCamera`를 추가한다.
- Inspector 연결 대상: `playerBody`에는 `Player`, `cameraPivot`에는 `PlayerCameraPivot`, 나머지 `mouseSensitivity`, `minPitch`, `maxPitch`를 입력한다.
- 완료 후 체크할 Checklist 경로: `Assets/Checklists/플레이어 관리자/02_HO_FirstPersonCamera_Checklist.md`

## 체크리스트 갱신 규칙과 전체 실행 순서 요약
- 각 Task 구현 직후 대응 Checklist 문서를 열고, 구조/Inspector 연결이 끝난 항목부터 체크한다.
- 플레이 모드 검증이 필요한 `미검증` 항목은 실제 테스트 후 체크하고, 미실행이면 그대로 둔다.
- 문서 작업을 별도로 수행한 경우에는 `Assets/Design/Checklist.md`에 완료 항목을 추가해 상위 작업 이력을 남긴다.
- 전체 실행 순서: 플레이어 관리자 `01 -> 02` → 전시 구조 관리자 `03 -> 04` → 작품 인터랙션 관리자 `05 -> 06` → 작품 구현 관리자 `07 -> 08` → AI 큐레이터 관리자 `09 -> 10 -> 11`
