# 시스템 기획서: 경계의 방: 근대에서 동시대로

## 콘텐츠 개요

`경계의 방: 근대에서 동시대로`는 PC Windows 기반 3D 가상 갤러리 콘텐츠로, 관람자가 1인칭 시점으로 전시 공간을 이동하며 근대 회화에서 현대의 설치, 영상, 자막, 인터랙티브 매체로 확장되는 미술의 흐름을 체험하는 교육형 전시 프로젝트다. 콘텐츠는 로비, 시간의 복도, 추상과 색면의 방, 매체 확장의 방, AI 큐레이터 포커스 존, 리플렉션 라운지로 이어지는 순차 동선을 중심으로 구성된다.

관람자는 키보드와 마우스를 사용해 공간을 탐색하고, 작품을 클릭해 상세 정보를 확인하며, 회화 확대 보기, 3D 오브젝트 회전, 영상 및 자막 감상, AI 큐레이터 도슨트 대화 같은 상호작용을 수행한다. 전시는 실제 미술관의 신뢰감 있는 공간 구성과 게임형 탐색의 몰입감을 결합해, 비전공자도 근현대 미술의 사조 변화와 매체 확장을 직관적으로 이해할 수 있도록 설계한다.

### 공간 디자인 방향

- 실제 미술관처럼 신뢰감 있는 화이트 큐브를 기본으로 한다.
- 공간마다 색, 조도, 사운드 밀도를 다르게 둔다.
- 바닥 유도선과 문 주변 조명으로 다음 공간을 안내한다.
- 작품은 시대 순서와 매체 변화가 보이도록 배치한다.
- 텍스트는 벽면 설명보다 팝업과 AI 큐레이터 대사 중심으로 제공한다.

### 사용자 경험 원칙

- 이동은 자유롭지만 전체 동선은 한 방향으로 읽히게 한다.
- 작품 선택 후 즉시 피드백을 준다.
- 설명은 짧게, 키워드는 명확하게 보여준다.
- 비전공자도 작품 변화의 이유를 직관적으로 이해하게 한다.
- 프로토타입에서는 핵심 룸, 대표 작품, 기본 인터랙션을 우선 검증한다.

- 핵심 경험: 플레이어가 여러 개의 전시실을 이동하며 근현대 미술의 변화, 매체 확장, 관람 방식의 변화를 AI 큐레이터의 안내와 함께 체험한다.
- 등장 인물:
  - 플레이어: 1인칭 시점 관람객
  - AI 큐레이터: 동선 안내, 작품 해설, 인터랙션 유도 역할
- 제작 방향: 실제 미술관의 신뢰감과 게임형 탐색의 몰입감을 결합한 교육형 전시 콘텐츠

## 2. 시나리오 기획

### 2.1 전시 콘셉트 및 기획 의도

**전시 콘셉트**  
근대 회화의 재현과 구성에서 출발해 추상, 설치, 영상, 인터랙티브 매체로 확장되는 흐름을 3D 공간 안에서 체험하게 하는 가상 전시다. 관람자는 단순히 작품을 보는 것이 아니라, 공간을 이동하고, 작품을 확대하고, 오브젝트를 회전하고, AI 큐레이터의 해설을 선택적으로 듣는 방식으로 미술사의 변화를 몸으로 이해한다.

**핵심 메시지**

- 미술은 사조의 나열이 아니라 시대, 기술, 관람자의 감각이 함께 바뀌는 과정이다.
- 근현대 미술은 평면 이미지에서 공간, 시간, 소리, 참여로 확장된다.
- 가상 갤러리는 실제 전시를 대체하기보다, 작품 이해를 돕는 새로운 관람 문법을 제공한다.

**기획 의도**

- 근현대 미술의 흐름을 비전공자도 직관적으로 이해할 수 있게 한다.
- PC 환경에서 키보드와 마우스만으로 안정적인 전시 관람 경험을 제공한다.
- 작품 감상, 도슨트, 인터랙션, 공간 연출을 하나의 동선으로 묶어 Unity 기반 3D 콘텐츠 제작의 기준 문서로 활용한다.

### 2.2 타겟 관람객

### 2.3 공간 동선 계획

전체 동선은 **로비 → 시간의 복도 → 추상과 색면의 방 → 매체 확장의 방 → AI 큐레이터 포커스 존 → 리플렉션 라운지 → 퇴장** 순서로 설계한다.

| 순서 | 공간 | 관람 목적 | 주요 연출 |
| --- | --- | --- | --- |
| 1 | 입장 로비 | 전시 주제와 조작 방식 인지 | AI 큐레이터 등장, 바닥 유도선, 전시실 입구 노출 |
| 2 | 시간의 복도 | 근대에서 현대로 이어지는 흐름 이해 | 연대형 벽면 배치, 작품 확대 인터랙션 |
| 3 | 추상과 색면의 방 | 재현에서 감각/구성으로 넘어가는 변화 체험 | 대형 캔버스, 조형물 회전, 조명 색 변화 |
| 4 | 매체 확장의 방 | 영상, 자막, 설치 매체 경험 | 비디오 월, 반응형 조명, 사운드 포인트 |
| 5 | AI 큐레이터 포커스 존 | 작품 해설과 팝업 UI 경험 | AI 큐레이터 도슨트, 정보 패널, 클릭 피드백 |
| 6 | 리플렉션 라운지 | 관람 내용 정리 및 퇴장 | 감상 요약 카드, 재관람/종료 선택 |

### 3.1 작품 라인업 및 스펙

실제 저작권 작품을 직접 복제하지 않고, 근현대 미술사의 조형 언어를 참고한 **오리지널 가상 작품**으로 구성한다.

| ID | 작품명 | 유형 | 배치 공간 | 포맷/스펙 | 메타데이터 |
| --- | --- | --- | --- | --- | --- |
| ART-001 | 도시의 단면 | 2D 이미지 | 시간의 복도 | PNG, 2048x2048 | 초기 모더니즘, 도시, 구조, 회색/청색 |
| ART-002 | 분절된 인물 | 2D 이미지 | 시간의 복도 | PNG, 2048x2048 | 형태 분해, 시점의 다중성, 교육용 비교 |
| ART-003 | 붉은 수평선 | 2D 이미지 | 추상과 색면의 방 | PNG, 4096x2048 | 색면 추상, 몰입형 대형 캔버스 |
| ART-004 | 부유하는 금속 | 3D 모델 | 추상과 색면의 방 | FBX/GLB, 10k~30k tris | 회전 인터랙션, 브러시드 메탈 재질 |

| ART-006 | 파동 아카이브 | 자막 | 매체 확장의 방 | WAV/OGG, 44.1kHz | 근거리 진입 시 페이드인 |
| ART-007 | 기억의 창 | 3D 설치 | AI 큐레이터 포커스 존 | FBX/GLB, 투명 재질 | 클릭 시 해설 팝업, AI 큐레이터 설명 |

### 3.3 스토리텔링 및 텍스트

#### 전시 월 텍스트

> 우리는 그림 앞에 서 있다고 생각하지만, 사실은 시대의 감각 앞에 서 있습니다.  
> 이 전시는 근대의 재현에서 현대의 참여형 매체로 이어지는 변화의 장면들을 3D 공간 안에 배치합니다.  
> 이동하고, 확대하고, 회전하고, 선택하며 당신만의 관람 경로를 완성해 보세요.

#### AI 큐레이터 기본 안내

- 입장 로비: "이 전시는 한 방향으로만 흘러가지 않습니다. 먼저 바닥의 푸른 유도선을 따라 이동해 보세요."
- 시간의 복도: "작품을 클릭하면 시대적 맥락과 조형 요소를 확대해서 볼 수 있습니다."
- 추상과 색면의 방: "여기서는 무엇을 그렸는지보다, 색과 면이 어떤 감각을 만드는지에 집중해 주세요."
- 매체 확장의 방: "현대 미술은 화면을 넘어 소리, 빛, 움직임, 관람자의 참여로 확장됩니다."
- 리플렉션 라운지: "마지막 공간에서는 방금 지나온 장면들을 다시 조합해 볼 수 있습니다."

#### 작품 팝업 안내문 포맷

- 작품명
- 제작 연도 또는 가상 연대
- 매체
- 핵심 키워드 3개
- 2~3문장 해설
- 인터랙션 안내: 확대, 회전, 영상 재생, 자막 듣기 등

## 기술 명세

### 플레이어 관리자 : 이동 명세
- 생성 클래스: `HO_PlayerMovement` / 부모 클래스: `MonoBehaviour` / 역할: 플레이어의 WASD, 방향키 이동과 기본 중력 처리를 담당한다.
- 입력은 Old Input의 `Input.GetAxis("Horizontal")`, `Input.GetAxis("Vertical")`만 사용한다.
- 이동 속도, 중력, CharacterController 참조는 `[SerializeField] private`로 노출한다.
- 검증 원칙: 중급 PC에서 끊김 없이 이동하고, 벽을 통과하지 않으며, 이동 속도가 과도하지 않은지 확인한다.
- 응답 원칙: 이동 입력 즉시 반응하고, 입력이 없으면 자연스럽게 정지한다.
- 주석 원칙: 클래스와 주요 함수에는 "플레이어 이동 처리"처럼 역할을 설명하는 주석을 포함한다.

-  역할: 마우스 이동으로 1인칭 시점 회전을 처리한다.
- 입력은 Old Input의 `Input.GetAxis("Mouse X")`, `Input.GetAxis("Mouse Y")`를 사용한다.
- 세로 회전은 멀미 방지를 위해 제한 각도를 둔다.
- 검증 원칙: 마우스 감도 기본값이 낮고 안정적인지, 급격한 흔들림이 없는지 확인한다.
- 응답 원칙: 마우스 이동량에 즉시 반응하되 회전은 부드럽게 보정한다.
- 주석 원칙: 카메라 회전 함수에는 회전축과 제한 목적을 설명하는 주석을 포함한다.

### 작품 인터렉션 관리자: 선택 인터랙션 명세 및 상세 정보 팝업 명세
- 생성 클래스: `HO_ArtworkSelector` / 부모 클래스: `MonoBehaviour` / 역할: 마우스 클릭 Raycast로 작품 선택을 처리한다.
- 입력은 Old Input의 `Input.GetMouseButtonDown(0)`과 `Input.mousePosition`을 사용한다.
- 선택 가능한 작품은 Layer 또는 태그로 구분한다.
- 검증 원칙: 작품 외 오브젝트 클릭 시 팝업이 뜨지 않고, 가까운 작품만 선택되는지 확인한다.
- 응답 원칙: 선택 성공 시 강조 표시와 상세 팝업 요청을 즉시 실행한다.
- 주석 원칙: Raycast 처리 함수에는 작품 선택 판정 역할을 설명하는 주석을 포함한다.

- 역할: 작품명, 매체, 키워드, 해설 텍스트를 팝업으로 표시한다.
- 작품 데이터는 프로토타입 단계에서 Inspector 배열 또는 ScriptableObject 중 간단한 방식으로 연결한다.
- 하나의 팝업 클래스에서 열기, 내용 갱신, 닫기 처리를 완료한다.
- 검증 원칙: 1920x1080 기준 텍스트가 잘리지 않고, 팝업 표시 중 이동 입력이 과하게 방해되지 않는지 확인한다.
- 응답 원칙: 작품 선택 즉시 팝업을 열고, 닫기 입력 시 관람 상태로 복귀한다.
- 주석 원칙: 팝업 열기/닫기 함수에는 UI 상태 변경 역할을 설명하는 주석을 포함한다.

### 작품 구현 관리자: 영상 매체 재생 명세 및 반응형 조명 및 공간 연출 명세
- 생성 클래스: `HO_MediaVideoPlayer` / 부모 클래스: `MonoBehaviour` / 역할: 영상 작품의 재생, 일시정지, 반복 재생을 담당한다.
- Unity `VideoPlayer` 컴포넌트를 사용하고, 클릭 또는 구역 진입 이벤트로 재생한다.
- 프로토타입에서는 스트리밍보다 로컬 에셋 재생을 우선한다.
- 검증 원칙: 영상이 끊기지 않고 반복되며, 다른 팝업과 충돌하지 않는지 확인한다.
- 응답 원칙: 재생 입력 후 지연이 길면 로딩 또는 상태 표시를 제공한다.
- 주석 원칙: 영상 상태 변경 함수에는 재생 상태 전환 역할을 설명한다.

- 역할: 구역 진입, 작품 선택, 영상 재생 상태에 따라 조명 강도와 색을 바꾼다.
- 실시간 조명 남용을 피하고, 프로토타입에서는 제한된 Light와 머티리얼 발광값만 제어한다.
- 하나의 클래스에서 대상 조명 목록과 전환 값을 관리한다.
- 검증 원칙: 프레임 저하 없이 분위기 변화가 보이고, 저조도 공간에서도 동선이 읽히는지 확인한다.
- 응답 원칙: 상태 변화 후 0.5~1초 내 부드럽게 전환한다.
- 주석 원칙: 조명 전환 함수에는 어떤 연출 상태로 바꾸는지 설명한다.

### AI 큐레이터 관리자 : 대화 자막 명세 실행 온오프 및 도슨트 스크립트 명세
- 생성 클래스: `HO_CuratorSubtitle` / 부모 클래스: `MonoBehaviour` / 역할: AI 큐레이터 대사 자막을 순차 표시한다.
- E 키 또는 구역 이벤트로 자막을 시작하며, 입력은 Old Input의 `Input.GetKeyDown(KeyCode.E)`를 사용한다.
- 플레이어가 작품의 중심기준 2미터 이내에 위치하게 되면 작품 상세를 유도하는 E키를 추천하는 UI를 보인다.
- 실제 LLM 연동 없이 고정 대사 배열로 프로토타입을 검증한다.
- 검증 원칙: 자막이 읽기 쉬운 길이로 표시되고, 다음 대사 진행이 명확한지 확인한다.
- 응답 원칙: 대화 시작 시 즉시 첫 문장을 표시하고, 종료 시 UI를 숨긴다.
- 주석 원칙: 자막 표시 함수에는 대사 진행 역할을 설명한다.

- 역할: ESC 또는 닫기 버튼 입력으로 팝업, 자막, 확대 보기를 닫고 관람 상태로 복귀한다.
- 입력은 Old Input의 `Input.GetKeyDown(KeyCode.Escape)`를 사용한다.
- 닫을 대상 UI를 우선순위로 정리해 하나의 클래스에서 복귀 흐름을 완료한다.
- 검증 원칙: 여러 UI가 겹쳤을 때 가장 최근 UI부터 닫히고, 닫은 뒤 이동/시점 조작이 복구되는지 확인한다.
- 응답 원칙: ESC 입력은 즉시 반응해야 하며, 복귀 후 선택 강조는 해제한다.
- 주석 원칙: 복귀 처리 함수에는 어떤 관람 상태로 되돌리는지 설명한다.

- 역할: 현재 구역과 작품에 맞는 도슨트 문장을 선택해 자막 시스템에 전달한다.
- 구역 ID, 작품 ID별 안내 문장은 Inspector에서 간단히 등록한다.
- 하나의 클래스에서 스크립트 선택과 전달까지 처리한다.
- 자막은 1인칭 화면의 하단에 흰 색 글씨로 제공한다.
- 검증 원칙: 잘못된 구역에서 다른 안내가 나오지 않고, 빈 데이터일 때 기본 문장을 표시하는지 확인한다.
- 응답 원칙: 관람 흐름을 방해하지 않도록 짧고 명확한 문장만 제공한다.
- 주석 원칙: 도슨트 선택 함수에는 어떤 기준으로 문장을 고르는지 설명한다.

### 전시 구조 관리자: 미니 동선 표시 UI 명세 및 공간 동선 및 구역 전환 명세
- 생성 클래스: `HO_MiniRouteUI` / 부모 클래스: `MonoBehaviour` / 역할: 현재 구역과 다음 구역 방향을 간단한 UI로 표시한다.
- `HO_GalleryZoneFlow`의 현재 구역 상태를 받아 아이콘 또는 텍스트 강조를 갱신한다.
- 프로토타입에서는 6개 구역 고정 표시로 구현한다.
- 검증 원칙: 현재 위치가 즉시 갱신되고, 화면을 과하게 가리지 않는지 확인한다.
- 응답 원칙: 구역 전환 후 UI 강조가 바로 바뀌어야 한다.
- 주석 원칙: UI 갱신 함수에는 현재 구역 표시 역할을 설명한다.

- 역할: 로비에서 리플렉션 라운지까지 구역 진입과 안내 상태를 관리한다.

- 검증 원칙: 구역 진입 순서가 기획 동선과 맞고, 역주행 시에도 상태가 깨지지 않는지 확인한다.

- 주석 원칙: 구역 전환 함수에는 어떤 구역 상태를 바꾸는지 설명하는 주석을 포함한다.
