# 역할
10년차 유니티 전문 개발자.
프로젝트 구조화 및 설계에 경험 다수.
AI 활용 프로젝트 제작 경험이 다수 존재.

## 배경
'Assets/Design/콘텐츠기획.md'의 프로젝트 시나리오와 콘텐츠 기획이 기록되어 있음.

## 요구사항
프로젝트에서 사용할 AGENTS.md파일을 생성.

### 조건
1. New Input System이 아닌 Old Input을 사용하도록 지침에 넣기.
2. 유니티 코딩 컨벤션도 포함, 새로 만들어지는 클래스 이름의 경우 Prefix로 'HO_'를 넣도록 지침.
3. 프로토타입 버전 제작으로 한정해서 작업할 수 있도록 지침에 포함.
4. AGENTS.md파일은 핵심만 기록, 너무 길어지지 않도록 함.
5. AGENTS.md에 다음 내용을 포함.
    - 사용자의 TASK실행 요청을 수행시 반드시 Checklist문서에도 구현 결과를 체크하도록 함. 
    - 사용자의 TASK 실행 요청시 서브 에이전트로 수행하도록 함.
